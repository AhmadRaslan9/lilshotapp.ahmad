LilShot Apple Modern Motion

حزمة واجهة فقط، ولا تحتوي على Firebase أو package.json أو app.json أو إعدادات Expo/Vite.

الجديد:
- شريط تنقل زجاجي بأسلوب Apple.
- مؤشر داكن يتحرك بسلاسة بين التبويبات.
- ارتداد خفيف للأيقونة المختارة وزر الكاميرا.
- انتقالات أسرع وأنعم بين صفحات التطبيق والتسجيل.
- حركة ضغط حديثة للأزرار والتبويبات والبطاقات.
- احترام إعداد Reduce Motion في الجهاز.
- الحفاظ على حذف صف اللحظات وقسم الدعوات وتصغير البار.
- الحفاظ على خطوط Kufam وPacifico وإصلاح اتجاه اللغة.

التثبيت فوق مشروعك الحالي:
unzip -o ~/lilshot-apple-modern-motion.zip -d .
npm run dev -- --force
