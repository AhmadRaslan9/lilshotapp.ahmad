# LilShot ☕

تطبيق لمشاركة لحظات القهوة واكتشاف المقاهي في السعودية، يستهدف iPhone بحسابات مستخدمين ومقاهٍ واشتراكات Plus.

## الحالة الحالية

المشروع نموذج React Native Web يعمل بواسطة Vite. نسخة iOS تحتاج تجهيز مدخل Native وتخزين الجلسة والبناء واختبار جهاز فعلي.

يتضمن الكود واجهات عربية بتصميم كريمي وزجاجي: ترحيب وتسجيل بالبريد، موجز لحظات وبوستات، كاميرا مركزية بإذن والتقاط ومعاينة، اكتشاف مقاهٍ ومنيو ومحفوظات وحساب وPlus. تسجيل البريد متصل بـFirebase وأفاد صاحب المشروع بأنه يعمل على جهازه. الصور والمقاهي والتفاعلات بيانات عرض؛ المعاينة لا تنشر الصور، والاشتراكات والموقع والمتابعة والإدارة بحاجة تنفيذ.

## تشغيل الويب

```sh
npm ci
npm run dev
```

للبناء: `npm run build`. إعدادات عميل Firebase لمشروع `lilshot-dbfe1` مضمّنة؛ لا تحتاج إنشاء `.env` لتحديد المشروع. تغيير المشروع اختياري عبر القيم الست الكاملة في `.env.example`. قواعد الوصول واختبار النشر والخدمات على iPhone خطوات منفصلة. الكاميرا تحتاج سياقاً آمناً وإذن المستخدم.

اختبارات إعداد Firebase وفلترة بيانات العرض دون اتصال: `node --test tests/*.test.mjs`.

لمن يشغّل المشروع بالفعل: أوقف الخادم، ثم `git pull --ff-only origin main` و`npm run dev`. لم تتغير الاعتماديات في تحديث التصميم.
