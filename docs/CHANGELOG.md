## 2026-09-06 — شاشة الترحيب حسب المرجع الجديد

- خلفية مقهى تغطي الشاشة، تدرج فاتح خلف عنوان عربي كبير، وبطاقة بيضاء بحواف دائرية أسفل الصورة.
- زر إنشاء حساب بلون إسبريسو، وزر تسجيل الدخول موصولان بالتنقل القائم إلى Firebase.
- Apple فقط ضمن خيارات الدخول الاجتماعي، مع توضيح أنه قريباً وتعطيله حتى تنفيذ الربط.
- دعم مساحة الأمان، أحجام أزرار مناسبة للمس، والتمرير للشاشات القصيرة.
- التحقق: نجح بناء Vite؛ تعذّر الفحص البصري بسبب ERR_BLOCKED_BY_CLIENT عند فتح localhost في متصفح بيئة العمل. لم يتم ادعاء تحقق بصري أو اختبار جهاز iPhone.
- هذا التحديث يخص شاشة الترحيب فقط. بقية إعادة التصميم السابقة بقيت مسودة محلية، وفق اختيار العمل صفحةً صفحةً.

- إضافة اختبارات محلية لاختيار الإعداد والعزل بين المشاريع، وتحديث دليل التجهيز.
- التحقق: نجحت 4 اختبارات إعداد محلية، وتهيئة SDK محلياً لـAuth وFirestore وStorage دون تسجيل دخول أو كتابة، وبناء Vite (529 وحدة) مع تحذير حجم الحزمة، وفحص git diff --check.
- لا إنشاء حسابات أو إرسال رسائل أو رفع صور أو تغيير قواعد/فوترة Firebase ضمن هذا التعديل. التحقق الحي وتفعيل Email/Password ما زالا مطلوبين.
